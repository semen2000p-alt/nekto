# ============================================================
#  NEKTO — РАЗМЕЩЕНИЕ В ОБЛАКЕ (без твоего компьютера)
#  Сайт работает 24/7 на бесплатном сервере, твой ПК можно выключать.
# ============================================================

Этот файл — пошаговая инструкция, чтобы выложить анонимный чат в интернет
так, чтобы другие люди заходили на него со своих устройств и своих сетей,
а твой компьютер был вообще не нужен.

Три варианта — от самого простого к самому надёжному:

## Вариант 1. Render + бот-пингер (просто, без карты)

Подходит, если не хочется возиться. Требует 2 бесплатных аккаунта:
GitHub + Render (оба без карты).

### Шаг 1 — залей код на GitHub

1. Зарегистрируйся на github.com (бесплатно).
2. Создай новый репозиторий: кнопка **New repository**, имя `nekto`,
   поставь галочку **Public** (так проще) и нажми Create.
3. Загрузи файлы из этой папки в репозиторий. Самый простой способ —
   на странице репозитория кнопка **Add file → Upload files**, перетащи туда:
     - `server.py`
     - `index.html`
     - `style.css`
     - `app.js`
     - `requirements.txt`
     - `start.bat` (не обязательно)
   и нажми **Commit changes**.

### Шаг 2 — разверни на Render

1. Зарегистрируйся на render.com (кнопка Sign up → Continue with GitHub).
2. В дашборде: **New → Web Service**.
3. Подключи свой GitHub-аккаунт, выбери репозиторий `nekto`.
4. Заполни поля:
   - Name: `nekto` (любое латинское)
   - Runtime: **Python 3**
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python server.py`
   - Instance Type: **Free**
5. Нажми **Create Web Service**. Через 3–5 минут сайт заработает.
6. Render сам даст ссылку вида `https://nekto.onrender.com` — это и есть
   твой адрес. Раздавай его друзьям!

### Шаг 3 — чтобы сайт не «засыпал»

Render бесплатно «засыпает» сайт через 15 минут без посетителей
(просыпается за 30–60 секунд при заходе). Чтобы этого избежать:

1. Зарегистрируйся на cron-job.org (бесплатно, без карты).
2. **Create Cronjob** → в поле URL вставь: `https://nekto.onrender.com/healthz`
3. **Execute every:** 30 minutes → Save (активируй).
4. Готово: каждые полчаса пингер «будит» твой сайт, он не засыпает.

> Примечание: даже если сайт всё-таки заснул (например, пингер отключили)
> — не страшно: первый же посетитель разбудит его, просто подождёт немного.

## Вариант 2. Oracle Cloud (навсегда бесплатный сервер, надёжнее)

Настоящий сервер, который не засыпает никогда. Минус: нужна банковская
карта при регистрации (только для проверки, деньги НЕ списываются —
это требование Oracle, не наше).

1. Зарегистрируйся на oracle.com/cloud → Always Free.
2. Создай VM (Ubuntu 22.04, ARM или x86) в регионе с Always Free.
3. Зайди по SSH, выполни:
   ```
   sudo apt update && sudo apt install -y python3-pip git
   git clone https://github.com/ТВОЙ_ЛОГИН/nekto.git
   cd nekto && pip install -r requirements.txt
   nohup python3 server.py &
   ```
4. Открой порт 8080 в Security List (Ingress) и в iptables/firewall.
5. Сайт доступен по `http://IP-адрес-сервера:8080`.

## Вариант 3. Свой домен и постоянный адрес

Бесплатно постоянный домен получить нельзя (обычно это ~1000 ₽/год).
Если появятся деньги — купишь домен и подключишь к Render/Oracle.

## После деплоя

- Ссылка вида `https://nekto.onrender.com` — отправляй её в мессенджеры,
  соцсети, куда угодно. Заходить могут откуда угодно, твой ПК выключен.
- Проверь работоспособность: открой ссылку в двух браузерах/вкладках,
  выбери одинаковые город, пол, возраст — они должны найти друг друга.

## Частые проблемы

- **Сайт не открывается** — подожди 30–60 секунд после первой попытки
  (бесплатный тариф «просыпается»), либо проверь, что сервис Deployed
  (зелёная точка в дашборде Render).
- **Ссылка «упала»** — Render перезапускает бесплатные сервисы раз в
  день, это нормально: через минуту снова работает.
- **Ошибка при деплое** — проверь, что в файле server.py первая строка
  `# -*- coding: utf-8 -*-` на месте и что порт берётся из переменной
  окружения (уже сделано).
