# НЕКТО — анонимный парный чат по городам России

Аналог `nekto.me` / `nekto-tyumen.ru`: **случайный парный чат**, где ты попадаешь в комнату ровно с одним человеком. Комнат может быть сколько угодно, в каждой максимум 2 человека.

Без регистрации, без рекламы, бесплатно.

> ## 🌐 Сайт в интернете БЕЗ твоего компьютера
> Чтобы люди заходили на сайт со своих устройств, а твой ПК можно было выключать —
> размести сервер в облаке. Это бесплатно: **полная инструкция в файле [`CLOUD.md`](CLOUD.md)**.
> Коротко: залей код на GitHub → разверни на Render → добавь бесплатный пингер,
> чтобы сайт не «засыпал». Ссылка вида `https://nekto.onrender.com` — и всё.

## Как это работает

1. Выбираешь **город** (подтверждается автоматически по IP или вручную из списка — «придумать» город нельзя, сервер проверит).
2. Указываешь **пол** и **возраст** (возрастная группа определяется сама: до 15 / 15–18 / 18–25 / 25–35 / 35+).
3. Выбираешь, **кого ищешь**: мужчину / женщину / не важно.
4. Нажимаешь «Найти собеседника» — появляется **экран ожидания со спиннером**.
5. Как только найдётся человек с **такими же параметрами** (город + возрастная группа), вы автоматически попадёте в пару.
6. В паре можно общаться, нажать «Следующий собеседник» — выйти из пары и искать нового (пара разрывается), или «Закончить» — вернуться в начало.

**Важно про безопасность:** взрослые (18+) никогда не попадают в пары с несовершеннолетними — поиск идёт строго внутри одной возрастной группы.

## Запуск (локально)

1. Двойной клик по `start.bat` (или в терминале: `python server.py`).
2. Открой в браузере **http://localhost:8080**.
3. Компьютер должен быть включён, окно с сервером не закрывай.

Другие устройства в твоей Wi-Fi-сети могут заходить по `http://<IP-компьютера>:8080` (IP сервер печатает при запуске).

> Если при запуске появляется ошибка про порт 8080 — значит, сервер уже запущен (возможно, фоновый). Закрой старое окно или останови процесс `python` в диспетчере задач и запусти снова.

## Бесплатная ссылка в интернет

Сайт становится публично доступен по бесплатной ссылке, **пока запущен `start.bat` на включённом компьютере**. Выключил комп или закрыл окно — ссылка перестала работать. Так устроены оба способа ниже.

### Способ 1 — Cloudflare Tunnel (рекомендуется, без регистрации)

1. Скачай `cloudflared.exe` со страницы Cloudflare (поиск: «cloudflared download windows») и положи рядом с этим файлом, либо: `winget install --id Cloudflare.cloudflared`.
2. Запусти сервер (`start.bat`).
3. В отдельном окне терминала:

   ```
   cloudflared tunnel --url http://localhost:8080
   ```

4. Через несколько секунд в консоли появится адрес вида `https://xxxxxxxx.trycloudflare.com` — **это и есть бесплатная ссылка**. Дай её друзьям из любого города — они откроют чат.
5. Можно создать файл `tunnel.bat`:

   ```bat
   @echo off
   cloudflared tunnel --url http://localhost:8080
   pause
   ```

   Запускаешь оба: `start.bat` и `tunnel.bat`.

### Способ 2 — ngrok

1. Скачай ngrok (`ngrok.com/download`), зарегистрируйся, вставь токен: `ngrok config add-authtoken ТВОЙ_ТОКЕН`.
2. Запусти сервер, затем в другом окне: `ngrok http 8080`.
3. Получишь ссылку вида `https://xxxx-xx-xx.ngrok-free.app`.

| | Cloudflare Tunnel | ngrok |
|---|---|---|
| Цена | бесплатно | бесплатно (с лимитами) |
| Регистрация | не нужна | нужна (один раз) |
| Ссылка | меняется при каждом запуске | меняется при каждом запуске |

Постоянный короткий адрес бесплатно возможен только с **белым IP** от провайдера: проброс порта 8080 на роутере + бесплатный DDNS (например, DuckDNS). Это описано ниже в разделе «Проброс порта».

## Как сделать, чтобы сайт находили в поиске («все могли найти»)

Честно: **бесплатно «привязать» постоянный домен и поднять сайт в поиске Яндекс/Google, работая с домашнего ПК через туннель, нельзя** — у бесплатных ссылок noindex, а поисковики не индексируют домашние IP. Реалистичные бесплатные варианты:

- **Покажи ссылку друзьям сам** — в мессенджерах и соцсетях. Для личного/дружеского чата этого обычно хватает.
- **Бесплатный хостинг статики** (GitHub Pages, Netlify, Vercel) даёт домен вида `имя.веб-сайт.app` — но там **нет сервера с WebSocket'ами**, поэтому парный чат там не заработает (только если вынести сервер отдельно, что не бесплатно).
- **Проброс порта + DDNS** (свой домен, но нужен белый IP и настройка роутера) — единственный способ получить постоянный адрес «на халяву».

## Проброс порта (постоянный адрес при белом IP)

1. Узнай у провайдера, есть ли у тебя белый (внешний) IP.
2. На роутере открой порт 8080 на твой компьютер (раздел «Виртуальные серверы» / Port Forwarding).
3. Зарегистрируй бесплатный DDNS-домен (например, на DuckDNS: `твой-адрес.duckdns.org`) и укажи его в настройках роутера.
4. Сайт будет доступен по `http://твой-адрес.duckdns.org:8080`.

## Частые проблемы

- **«Город не подтверждён»** — выбери город из списка и подожди, пока появится зелёное «Город подтверждён». Если город определяется по IP — он подставится сам.
- **Сайт не открывается** — сервер не запущен или окно `start.bat` закрыто.
- **Ссылка Cloudflare не работает** — оба процесса (`start.bat` и `cloudflared`) должны работать одновременно.
- **Никто не находится** — для пары нужно, чтобы одновременно ждали двое с одинаковыми параметрами (город + возрастная группа). Если собеседников нет — будет крутиться спиннер. Это нормально.
- **Сообщения не отправляются** — открывай сайт через `http://localhost:8080`, а не двойным кликом по `index.html` (WebSocket не работает из «файлового» режима).
